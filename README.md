# exerciciosDeLogicadeProgramacaoFaccat
Este projeto reúne a resolução prática dos exercícios de lógica de programação da apostila Faccat (Faculdades Integradas de Taquara). Desenvolvido em VisuAlg, o repositório serve como um guia estruturado para consolidar os fundamentos da computação, raciocínio lógico e construção de algoritmos.
